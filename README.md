# SVAMITVA-Geospatial-Intelligence
Designed an AI-based geospatial mapping system to automatically detect rural infrastructure from drone orthophotos using ConvNeXt-Tiny deep learning and ensemble machine learning techniques.
Achieved 91\% accuracy with ConvNeXt-Tiny and 86\% accuracy using a soft-voting ensemble (Random Forest, Gradient Boosting, Logistic Regression).
Generated GIS outputs (.gpkg) for mapping and planning applications.
